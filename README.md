# Word Counter

A beginner-friendly Python program that counts words and characters in a sentence or paragraph.

## Features
- Counts total words
- Counts total characters
- Counts characters without spaces
- Handles empty input

## Example

Input:
```text
Python is easy to learn
```

Output:
```text
Word Count                : 5
Character Count           : 24
Characters Without Spaces : 20
```

## How to Run

```bash
python word_counter.py
```

## Concepts Used
- Strings
- `split()`
- `replace()`
- `len()`
- Functions
- User input
- Conditions
